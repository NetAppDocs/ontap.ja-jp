= 新しいボリュームでデフォルトで ONTAP ARP を有効にする
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
ONTAP 9.10.1以降では、ストレージVM（SVM）を構成して、新しいNASボリュームがデフォルトで学習モードの自律型ランサムウェア保護（ARP）で有効になるようにすることができます。この設定は、System ManagerまたはONTAP CLIを使用して変更できます。


NOTE: ONTAP 9.16.1以降を実行している場合は、link:enable-default-arpai.html["新しいボリュームでARP/AIをデフォルトで有効にする"]を参照してください。


NOTE: ONTAP 9.13.1 から 9.17.1 の場合、FlexGroup ボリュームは以前の ARP モデルを使用しており、学習期間が必要です。この手順は、ONTAP 9.17.1 以前を実行している FlexGroup ボリュームに使用します。

.タスク概要
デフォルトでは、新しいボリュームはARPが無効の状態で作成されます。SVMでARPをデフォルトで有効にすると、そのSVMで作成された新しいボリュームは自動的にARP学習モードで起動します(`dry-run`状態）。ARPが有効になっていない既存のボリュームは、SVMのデフォルト設定を変更してもARPの有効化状態は変更されません。

ONTAP 9.13.1以降、適応型学習がデフォルトで有効になっており、学習期間が十分であると判断された後、ARPは自動的に学習モードからアクティブモードに切り替わります。この自動切り替え機能を無効にして、手動で切り替えを制御することもできます。

[[arp-enablement-default-behavior-table]]
自律型ランサムウェア保護を有効にすると、環境およびONTAPバージョンによっては移行期間に入る場合があります。

[cols="25,25,50"]
|===
| ボリューム タイプ | ONTAPのバージョン | 有効化後の動作 


.2+| NAS FlexGroup | ONTAP 9.18.1以降 | ARP/AIは学習期間なしですぐにアクティブになります 


| ONTAP 9.13.1 から 9.17.1 | ARPは30日間学習モードで開始されます 


.2+| NAS FlexVol | ONTAP 9.16.1以降 | ARP/AIは学習期間なしですぐにアクティブになります 


| ONTAP 9.10.1から9.15.1 | ARPは30日間学習モードで開始されます 


| SANボリューム | ONTAP 9.17.1以降 | ARP/AI は直ちにアクティブになり、初期の保守的なしきい値から移行する前に、適切なアラートしきい値を確立するための評価期間を開始します。 
|===
.開始する前に
* NFSまたはSMB（またはその両方）プロトコルが有効になっているStorage VM（SVM）。
* ボリュームのアクティブなlink:../concepts/namespaces-junction-points-concept.html["ジャンクションパス"]。
* ONTAPバージョンのlink:index.html#licenses-for-autonomous-ransomware-protection["正しいライセンス"]。
* （推奨）マルチ管理者検証（MAV）が有効（ONTAP 9.13.1以降）。link:../multi-admin-verify/enable-disable-task.html["複数管理者による検証を有効にする"]を参照してください。


.手順
System Manager または ONTAP CLI を使用して、SVM レベルで新規ボリュームに対して ARP をデフォルトで有効にすることができます。

[role="tabbed-block"]
====
.System Manager
--
. *ストレージVM* を選択し、次にARPで保護するボリュームを格納するストレージVMを選択します。
. *設定*タブに移動します。*セキュリティ*の下にある*ランサムウェア対策*タイルを見つけて、image:icon_pencil.gif["編集アイコン"]を選択します。
. ランサムウェア対策（ARP）を有効にするには、チェックボックスをオンにします。ストレージVM内のすべての対象ボリュームでARPを有効にするには、追加のチェックボックスをオンにします。
. 「十分な学習が終わったら、学習モードからアクティブモードに自動的に切り替える」を選択すると、ARP が最適な学習期間を決定し、アクティブモードへの切り替えを自動化します（ONTAP 9.13.1 以降）。


--
.CLI
--
*既存の SVM を変更して、新しいボリュームの学習モードで ARP をデフォルトで有効にする：*

[source, cli]
----
vserver modify -vserver <svm_name> -anti-ransomware-default-volume-state dry-run
----
*新規ボリューム用に、ARPをデフォルトで有効にした（学習モードの）新しいSVMを作成します：*

[source, cli]
----
vserver create -vserver <svm_name> -anti-ransomware-default-volume-state dry-run
----
*アクティブモードへの自動学習移行を無効にする（オプション）：*

ONTAP 9.13.1 から 9.15.1 を実行していて、SVM に関連付けられているすべてのボリュームについて、学習モードからアクティブモードへの切り替えを手動で制御する場合：

[source, cli]
----
vserver modify -vserver <svm_name> -anti-ransomware-auto-switch-from-learning-to-enabled false
----
*ARP状態を確認します：*

[source, cli]
----
security anti-ransomware volume show
----
--
