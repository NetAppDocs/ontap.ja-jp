= ONTAP自律型ランサムウェア保護について学ぶ
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
自律型ランサムウェア対策はONTAPに直接組み込まれており、NASおよびSAN環境におけるワークロード分析を実行し、ランサムウェア攻撃を示唆する可能性のある異常なアクティビティを事前に検知して警告を発します。リアルタイムで動作し、ストレージへの書き込みやストレージからの読み出し時にデータを処理して、データを保護するために自動的に対応します。

ONTAP 9.16.1以降、自律型ランサムウェア対策では、事前学習済みの機械学習モデル（ARP/AI）を使用し、学習期間を必要とせずに即座にアクティブな保護を提供します。NAS（ONTAP 9.16.1以降）およびSAN（ONTAP 9.17.1以降）のボリュームをサポートします。ONTAP 9.10.1から9.15.1については、オリジナルの自律型ランサムウェア対策（ARP）モデルがNAS環境をサポートしており、アクティブな検出を開始する前に学習期間が必要です。



[[current-documentation-for-your-ontap-version]]
== お使いのONTAPバージョンの最新ドキュメント

ARP/AI は、ONTAP 9.16.1 以降の現在のデフォルトモデルです。元の ARP モデルは ONTAP 9.10.1 から 9.15.1 に適用されます。お使いの ONTAP バージョンのドキュメントを選択してください：

* *link:learn-about-arpai.html["ARP/AI （ONTAP 9.16.1以降）"]*: 即時アクティブ保護、SANサポート、および自動セキュリティアップデートを備えた機械学習モデル。
* *link:learn-about-arp.html["ARP （ONTAP 9.10.1～9.15.1）"]*: NASに特化しており、アクティブな保護が開始される前に学習期間があります。ONTAP 9.16.1 および 9.17.1 の FlexGroup ボリュームにも適用されます。



NOTE: 元の ARP モデルは、ONTAP 9.14.1 以降、新しい機能改善を受けていません。ONTAP 9.16.1 以降で FlexVol ボリュームを使用している場合は、ARP/AI のドキュメントを参照してください。FlexGroup ボリュームは、ONTAP 9.17.1 まで元の ARP モデルを使用し、ONTAP 9.18.1 以降では ARP/AI によってサポートされます。



[[licenses-for-autonomous-ransomware-protection]]
== 自律型ランサムウェア対策のライセンス

Autonomous Ransomware Protectionのサポートは、link:https://kb.netapp.com/onprem/ontap/os/ONTAP_9.10.1_and_later_licensing_overview["ONTAP Oneライセンス"^]に含まれています。ONTAP One ライセンスをお持ちでない場合は、お使いの ONTAP のバージョンによって異なる、Autonomous Ransomware Protection 用の他のライセンスをご利用いただけます。

[cols="2*"]
|===
| ONTAPリリース | ライセンス 


 a| 
ONTAP 9.11.1以降
 a| 
`Anti_ransomware`



 a| 
ONTAP 9.10.1
 a| 
`MT_EK_MGMT`（マルチテナント鍵管理）

|===
* ONTAP 9.10.1 から ONTAP 9.11.1 以降にアップグレードする場合で、Autonomous Ransomware Protection がすでにシステムに構成されている場合は、新しい `Anti-ransomware`ライセンスをインストールする必要はありません。新しい Autonomous Ransomware Protection 構成には、新しいライセンスが必要です。
* ONTAP 9.11.1 以降から ONTAP 9.10.1 にリバートする場合、 `Anti_ransomware`ライセンスで Autonomous Ransomware Protection を有効にしていると、警告メッセージが表示され、再設定が必要になる場合があります。link:../revert/anti-ransomware-license-task.html["Autonomous Ransomware Protectionのリバートについて"]。




[[ontap-ransomware-protection-strategy]]
== ONTAPのランサムウェア保護戦略

効果的なランサムウェア保護には、連携して機能する複数の保護層が必要です。

ONTAPにはFPolicy、スナップショット、SnapLock、およびActive IQ Digital Advisor（Digital Advisorとも呼ばれます）などの機能が含まれており、ランサムウェアからの保護を支援しますが、Autonomous Ransomware Protectionはさらなる防御層を提供します。

NetAppポートフォリオでランサムウェアから保護するその他の機能の詳細については、以下を参照してください：

* link:https://docs.netapp.com/us-en/ontap-technical-reports/ransomware-solutions/ransomware-active-iq.html["NetAppのランサムウェア対策ポートフォリオ"^]
* link:https://docs.netapp.com/us-en/netapp-solutions-dataops/cyber-vault/ontap-cyber-vault-ps-hardening.html["PowerShellを使用したONTAPサイバーボールトの強化"^]




[[autonomous-ransomware-protection-with-ai-arpai-and-legacy-arp-feature-comparison]]
== AI搭載自律型ランサムウェア対策（ARP/AI）と従来のARPの機能比較

[cols="1,1,1"]
|===
| モデル | ARP | ARP/AI 


| ONTAPバージョン | ONTAP 9.10.1から9.15.1 | ONTAP 9.16.1以降 


| 検出方法 | ファイルアクティビティ、データエントロピー、ファイル拡張子の種類を分析します | 大規模なフォレンジックデータセットでトレーニングされた AI / 機械学習モデル。エントロピーとファイルの挙動を分析 


| 学習期間 | NAS FlexVol ボリュームには30日間の学習モードが必要です（自動切り替えは ONTAP 9.13.1 以降で利用可能） | 学習期間なし。有効化後すぐにアクティブになります 


| ボリュームタイプのサポート  a| 
* FlexVol：ONTAP 9.10.1 ～ 9.15.1
* FlexGroup：ONTAP 9.13.1 ～ 9.17.1
* SAN：サポートされていません

 a| 
* FlexVol：ONTAP 9.16.1以降
* FlexGroup：ONTAP 9.18.1以降
* SAN：ONTAP 9.17.1以降（評価期間付き）




| Snapshotの作成 | 高いエントロピー、新しいファイル拡張子、またはファイル操作の急増によってトリガーされます | 攻撃確認時に作成されます（ONTAP 9.16.1）。ONTAP 9.17.1以降、スナップショットは4時間間隔で固定で作成されるようになりました。 


| Snapshot の保持 | 管理者が疑わしいアクティビティをクリアするまで保持されます | デフォルトでは12時間。攻撃の確認に基づいて延長されます（誤検知の場合は24時間、確認された陽性の場合は7日間） 


| 更新 | 静的検出ロジック（ONTAPアップグレードでのみ更新） | ONTAPリリースに依存しない自動セキュリティ更新 


| 導入 | ボリュームごとの手動有効化またはSVMレベルのデフォルト設定 | ボリュームごとの手動有効化またはSVMレベルのデフォルト設定。ONTAP 9.18.1以降のサポートされているシステムでは、クラスタレベルですべての新しいボリュームをデフォルトで有効化 


| 評価期間 | 該当なし | SANボリュームの場合、ベースラインの暗号化しきい値を確立するために2～4週間必要です。ONTAP 9.17.1以降、ONTAPで検出されたハイパーバイザー仮想ディスクを含むNAS FlexVolボリュームにも必要です。 
|===
