= ONTAP Vscanパートナー解決策の詳細
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetAppは、Trellix、Symantec、Trend Micro、Sentinel One、Deep Instinct、OPSWATと連携し、ONTAP Vscanテクノロジーを基盤とした業界最先端のマルウェア対策およびウイルス対策解決策を提供しています。これらの解決策は、ファイルのマルウェアスキャンや、影響を受けたファイルの修復に役立ちます。
