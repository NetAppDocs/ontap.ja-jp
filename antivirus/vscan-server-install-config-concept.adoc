= ONTAP Vscan サーバーのインストールと構成
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
1つ以上のVscanサーバを設定して、システム上のファイルが確実にウイルス スキャンされるようにします。ウイルス対策ソフトウェアのサーバへのインストールと設定については、各ベンダーの手順に従ってください。

NetAppが提供するREADMEファイルの手順に従って、ONTAPアンチウイルスコネクタをインストールおよび設定します。または、link:install-ontap-antivirus-connector-task.html["ONTAP Antivirus Connectorのインストール ページ"]の手順に従ってください。

[NOTE]
====
ディザスタ リカバリ構成およびMetroCluster構成では、プライマリ / ローカルONTAPクラスタとセカンダリ / パートナーONTAPクラスタのそれぞれに対してVscanサーバを個別に設定する必要があります。

====


[[antivirus-software-requirements]]
== ウイルス対策ソフトウェアの要件

* ウイルス対策ソフトウェアの要件については、ベンダー提供のドキュメントを参照してください。
* Vscanでサポートされているベンダー、ソフトウェア、およびバージョンについては、link:../antivirus/vscan-partner-solutions.html["Vscanパートナー ソリューション"]を参照してください。




[[ontap-antivirus-connector-requirements]]
== ONTAP Antivirus Connectorの要件

各SVMは、ICAPまたはAntivirus Connectorのいずれかを使用し、両方を使用することはありません。

* ONTAPアンチウイルスコネクタは、NetApp Support Siteのlink:http://mysupport.netapp.com/NOW/cgi-bin/software["ソフトウェア ダウンロード"^]ページからダウンロードできます。
* ONTAP Antivirus Connector でサポートされている Windows バージョンと相互運用性の要件については、link:../antivirus/vscan-partner-solutions.html["Vscanパートナー ソリューション"]を参照してください。
+
[NOTE]
====
クラスター内の異なる Vscan サーバーに異なるバージョンの Windows サーバーをインストールできます。

====
* Windows Serverに.NET 3.0以降がインストールされている必要があります。
* Windows ServerでSMB 2.0が有効になっている必要があります。




[[icap-capable-scan-engine-requirements]]
== ICAP対応スキャンエンジンの要件

各SVMは、ICAPまたはAntivirus Connectorのいずれかを使用し、両方を使用することはありません。

* ONTAP 9.20.1以降、ONTAPはAntivirus Connectorを必要としないICAPベースのスキャンパスをサポートしています。
* ICAPはLinuxベースのスキャンエンジンをサポートしており、Windows、.NET、またはSMB 2.0を必要としません。



NOTE: ONTAP 9.20.1からそれ以前のリリースにリバートする場合は、まずすべてのICAP設定を削除する必要があります。

link:icap-vscan.html["ICAPベースのVscan構成"] の詳細をご覧ください。
