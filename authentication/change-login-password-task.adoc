= ONTAP管理者パスワードを変更する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
クラスターのセキュリティを維持するために、初回ログインの直後、およびその後も定期的に、初期ONTAP管理者パスワードを変更する必要があります。

ONTAP 9.20.1以降では、ユーザーアカウントでパスワード有効期限アラートが設定されている場合、System Managerはパスワードの有効期限が切れる14日前からバナーアラートを表示します。ログインするたびにアラートが更新され、残り日数が表示されます。

.タスク概要
新しいパスワードは次のルールに従う必要があります。

* ユーザ名を含めることはできません。
* 8文字以上である必要があります。
* 英文字と数字がそれぞれ1文字以上含まれている必要があります。
* 直近の6つのパスワードと同じパスワードは使用できません。



NOTE:  `security login role config modify`コマンドを使用して、特定のロールに関連付けられたアカウントのパスワードルールを変更できます。

.開始する前に
* 自分のパスワードを変更するには、クラスタ管理者またはSVM管理者である必要があります。
* 他の管理者のパスワードを変更するには、クラスタ管理者である必要があります。


.手順
システムマネージャまたはONTAPコマンドラインインターフェース（CLI）を使用してパスワードを変更します。

[role="tabbed-block"]
====
.System Manager
--
. System Managerで、*Cluster > Settings*を選択します。
. *ユーザーと役割*で、*ユーザー*を選択します。
. パスワードを変更するユーザーアカウントの横にあるimage:icon_kabob.gif["メニュー"]を選択し、*パスワードの変更*を選択します。
. 新しいパスワードを入力します。
. 新しいパスワードを再度入力して確認し、*保存*を選択します。


--
.CLI
--
SVM管理者の場合は、 `security login password`コマンドを使用して自身のパスワードを変更できます。クラスタ管理者の場合は、 `security login password`コマンドを使用して任意の管理者のパスワードを変更できます。

. 管理者パスワードを変更します： `security login password -vserver _svm_name_ -username _user_name_`
+
次のコマンドは、SVM `vs1.example.com`の管理者 `admin1`のパスワードを変更します。現在のパスワードを入力するよう求められ、次に新しいパスワードを入力して再入力します。

+
[listing]
----
vs1.example.com::>security login password -vserver engData -username admin1
Please enter your current password:
Please enter a new password:
Please enter it again:
----


--
