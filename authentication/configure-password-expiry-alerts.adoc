= System ManagerでONTAPユーザーパスワードの有効期限切れアラートを設定する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP 9.20.1以降では、ユーザーアカウントに関連付けられたロールでパスワードの有効期限アラートが設定されている場合、パスワードの有効期限が切れる14日前から、ログイン直後にSystem Managerのページ上部にバナーアラートが表示されます。アラートはユーザーがログインするたびに更新され、パスワードの有効期限が切れるまでの残り日数が表示されます。管理者ロールを追加または編集する際に、有効期限アラートを設定できます。

.手順
. *Cluster > Settings*を選択します。
. *ユーザーとロール*の横にあるimage:icon_arrow.gif["矢印アイコン"]を選択します。
. ユーザーロールの追加または編集時に、パスワード有効期限切れアラートを設定します。
+
** ユーザーロールを追加する際に設定するには、*ロール* で image:icon_add.gif["追加アイコン"] を選択します。ロールの名前を入力し、パスワードの有効期間とパスワードの有効期限切れアラートを選択します。
** ユーザーロールを編集する際に設定を行うには、*Roles*でユーザーロールを選択します。*Edit*を選択し、パスワードの有効期限を選択します。
** *追加*を選択します。




.結果
ユーザーは、ログイン直後、パスワードの有効期限が切れる指定した日数の前から、System Managerのページ上部にバナーアラートを受け取ります。ユーザーがログインするたびにアラートが更新され、パスワードの有効期限が切れるまでの残り日数が表示されます。
