= ONTAP FlexCacheライトバックの前提条件
:allow-uri-read: 


[role="lead"]
FlexCacheをライトバック モードで展開する前に、パフォーマンス、ソフトウェア、ライセンス、およびシステム構成の要件を満たしていることを確認してください。



[[cpu-and-memory]]
== CPUおよびメモリ

ライトバック対応キャッシュによって開始されるライトバック メッセージを処理するために、各オリジン クラスタ ノードには少なくとも128GBのRAMと20個のCPUを搭載することを__**強く推奨**__します。これはA400以上に相当します。オリジン クラスタが複数のライトバック対応FlexCachesのオリジンとして機能する場合は、より多くのCPUとRAMが必要になります。


CAUTION: ワークロードに小さすぎるオリジンを使用すると、ライトバック対応キャッシュまたはオリジンのパフォーマンスに大きな影響を与える可能性があります。



[[ontap-version]]
== ONTAPのバージョン

* オリジンは ONTAP 9.15.1 以降を実行している必要があります。ただし、ONTAP 9.15.1 には FlexCache 書き戻しに必要な修正と改善がすべて含まれているわけではないため、本番環境のワークロードには推奨されません。FlexCache 書き戻しの大幅な機能強化は ONTAP 9.17.1P1 で導入されました。オリジンクラスタとキャッシュクラスタの両方で、9.17.1P1 以降の最新推奨リリースを実行することを**強く**お勧めします。ONTAP 9.17.1 を実行できない場合は、9.16.1 の最新 P リリースが次に推奨されるリリースです。
+

NOTE: ご使用の環境に FlexCache のライトバックを実装する前に、link:flexcache-write-back-guidelines.html["FlexCache 書き戻しガイドライン"] を確認することを強くお勧めします。

* ライトバック モードで動作する必要があるキャッシュ クラスタは、ONTAP 9.15.1 以降を実行している *_必要があります_* 。
* ライトバックモードで動作する必要のないキャッシングクラスタは、FlexCacheボリュームをサポートする任意の ONTAP バージョンで実行できます。




[[licensing]]
== ライセンス

ライトバック動作モードを含むFlexCacheは、ONTAPの購入に含まれています。追加のライセンスは必要ありません。



[[peering]]
== ピアリング

* オリジン クラスタとキャッシュ クラスタはlink:../flexcache-writeback/flexcache-writeback-enable-task.html["クラスタピアリング済み"]
* オリジン クラスターとキャッシュ クラスター上のサーバー仮想マシン（SVM）にはlink:../flexcache-writeback/flexcache-writeback-enable-task.html["vserver のピア関係"]、FlexCacheオプションが必要です。



NOTE: キャッシュ クラスタを別のキャッシュ クラスタにピアリングする必要はありません。また、キャッシュSVMを別のキャッシュSVMとピアリングする必要もありません。
