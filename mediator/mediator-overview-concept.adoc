= MetroCluster IPおよびSnapMirrorアクティブ同期向けONTAPメディエーターについて
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP Mediatorは、高可用性（HA）メタデータ用の永続的でフェンスされたストアの提供、クォーラム決定を支援する同期ノード健常性クエリ機能の提供、およびコントローラの稼働状況を確認するpingプロキシとして機能することで、SnapMirror active syncおよびMetroCluster IPをサポートします。

ONTAP Mediatorは、ONTAPクラスタとは別の第3の障害ドメインにあるLinuxホスト上で実行され、HAメタデータ用の永続的でフェンスされたストアを提供します。ONTAPは、Mediatorのノードヘルス照会機能およびpingプロキシ機能とともにこのストアを使用して、SnapMirrorアクティブ同期関係とMetroCluster IP構成を監視します。

* ONTAP Mediatorは、ノード管理LIFとクラスタ管理LIFを使用して、複数の冗長なパスを介して各クラスタと通信します。これにより、ONTAPは完全なサイト障害と単一のInterSwitchリンク（ISL）障害を区別できるようになります。
* SnapMirrorアクティブ同期では、クラスタがピアとONTAPメディエーターの両方への接続を失った場合、ONTAPはピアを到達不能として扱い、残っているコピーに自動的にフェイルオーバーできます。
* MetroCluster IP構成では、ONTAP Mediatorは、MetroClusterノードの状態情報を保存し、障害発生時に適切な対応策を決定するのを支援することで、Mediator支援の自動計画外スイッチオーバー（MAUSO）を支援します。


ONTAP Mediatorのオンプレミス版をインストールまたはアップグレードするには、link:https://docs.netapp.com/us-en/ontap-mediator/index.html["ONTAP Mediator ドキュメント"^]を参照してください。

ONTAP 9.17.1以降で利用可能なONTAP Cloud Mediatorの詳細については、link:../snapmirror-active-sync/index.html["SnapMirror アクティブ同期のドキュメント"]を参照してください。
