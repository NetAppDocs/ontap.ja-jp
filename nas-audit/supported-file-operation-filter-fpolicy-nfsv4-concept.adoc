= ONTAP でサポートされている NFSv4 の FPolicy ファイル操作とフィルタ
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
FPolicyイベントを設定する際には、NFSv4のファイル アクセス処理の監視では特定のファイル処理とフィルタの組み合わせだけがサポートされることを考慮する必要があります。

ONTAP 9.15.1以降のFPolicyでは、NFSv4.1プロトコルがサポートされます。

ONTAP 9.19.1以降、管理者はSVMレベルでNFSv4.2の可用性を制御し、System Manager、CLI、またはREST APIを使用して個々のストレージVMのプロトコルを有効または無効にすることができます。

ONTAP 9.20.1以降、FPolicyはNFSv4.2ファイルアクセスイベントの監視をサポートしています。これには、拡張属性（xattr）書き込みの新しいファイル操作や、ラベル付きNFSアクティビティのセキュリティラベルフィルタが含まれます。詳細については、link:../nfs-admin/enable-disable-nfs-task.html["ONTAP SVMでのNFSの有効化または無効化"]をご覧ください。


NOTE: セキュリティラベルフィルタ(`setattr_with_security_label_change`および `getattr_with_security_label_read`）では、SVMでNFSv4.2セキュリティラベル（ラベル付きNFS）を有効にする必要があります。link:../nfs-admin/enable-nfsv42-security-labels-task.html["NFSv4.2セキュリティラベルの有効化"]の詳細をご覧ください。 `getxattr`および `listxattrs`は読み取り専用の処理であり、FPolicyでは監視されません。
