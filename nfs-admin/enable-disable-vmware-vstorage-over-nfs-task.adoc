= ONTAP NFS経由でVMware vStorageを有効または無効にする
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ストレージ仮想マシン（SVM）でのNFS経由のVMware vStorageのサポートは、 `vserver nfs modify`コマンドを使用して有効または無効にすることができます。この設定は、コピー オフロードやスペース リザベーションなどのVMware VAAI over NFS処理を制御します。

.タスク概要
デフォルトでは、VMware vStorage over NFSのサポートは無効になっています。

ONTAP 9.20.1以降では、ONTAP NFSでVMware vStorageを有効にすると、シンプロビジョニングされたNFSv3およびNFSv4.1データストアの自動スペース解放もサポートされます。

.手順
. SVMの現在のVMware vStorage over NFS設定を確認します：
+
`vserver nfs show -vserver vserver_name -fields vstorage`

. 次のいずれかを実行します。
+
[cols="2*"]
|===
| 状況 | 入力するコマンド 


 a| 
VMware vStorageのサポートを有効にする
 a| 
`vserver nfs modify -vserver vserver_name -vstorage enabled`



 a| 
VMware vStorageのサポートを無効にする
 a| 
`vserver nfs modify -vserver vserver_name -vstorage disabled`

|===
. 設定が更新されていることを確認してください：
+
`vserver nfs show -vserver vserver_name -fields vstorage`



.終了後の操作
この機能を使用する前に、VMware VAAI用NetApp NFSプラグインをインストールする必要があります。自動的な領域解放には、バージョン3.0以降が必要です。

VMwareホスト、プラグイン、および相互運用性の要件については、NetApp VMware VAAI用NFSプラグインのドキュメントおよびNetApp Interoperability Matrix Toolを参照してください。
