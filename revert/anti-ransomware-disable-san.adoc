= ONTAP 9.17.1から戻す前に、SANボリュームのAutonomous Ransomware Protectionを無効にします
:allow-uri-read: 


[role="lead"]
SAN ボリュームの ONTAP ARP/AI 機能は、ONTAP 9.16.1 以前ではサポートされていません。ロールバック後のバージョンで実際の検出を行わずにこの機能がアクティブなままになり、CPU およびディスクリソースを消費することを防ぐため、ONTAP 9.16.1 以前のバージョンに戻す前に SAN ボリュームの ARP/AI を無効にすることをお勧めします。

.手順
[role="tabbed-block"]
====
.System Manager
--
. *Storage > Volumes* を選択し、ボリュームの名前を選択します。
. *ボリューム* 概要の *セキュリティ* タブで、*ステータス* を選択して、有効から無効に切り替えます。


--
.CLI
--
. ボリューム上のランサムウェア保護を無効にします：
+
[source, cli]
----
security anti-ransomware volume disable -volume <vol_name> -vserver <svm_name>
----
