= ONTAP のリバート前に Autonomous Ransomware Protection のアクティビティ警告を解決する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAP 9.17.1以前にリバートする前に、Autonomous Ransomware Protectionによって報告された異常なアクティビティの警告に対応し、関連するAutonomous Ransomware Protectionのスナップショットをすべて削除する必要があります。

.開始する前に
Autonomous Ransomware Protectionのスナップショットを削除するには、「Advanced」権限が必要です。

.手順
. link:../anti-ransomware/respond-abnormal-task.html["自律型ランサムウェア対策"]から報告された異常なアクティビティの警告に応答し、潜在的な問題を解決します。
. 元に戻す前に、*疑わしいファイルタイプの更新とクリア*を選択して決定を記録し、通常のAutonomous Ransomware Protection監視を再開することで、これらの問題が解決したことを確認してください。
. 警告に関連付けられている Autonomous Ransomware Protection のスナップショットを一覧表示するには、次のコマンドを実行します。
+
[source, cli]
----
volume snapshot snapshot show -fs-version 9.18
----
. 警告に関連付けられているAutonomous Ransomware Protectionのスナップショットをすべて削除します。
+

NOTE: このコマンドは、現在のバージョンの ONTAP で使用される形式を持つすべてのスナップショットを削除します。自律型ランサムウェア対策のスナップショットだけとは限りません。このコマンドを実行する前に、削除されるすべてのスナップショットに対して必要な措置を講じていることを確認してください。

+
[source, cli]
----
volume snapshot prepare-for-revert -node <node_name>
----
