= お使いの ONTAP システムでサポートされている FC ターゲットポート速度を確認する
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
FCターゲットポートは、FCプロトコルとまったく同じ方法でFC-NVMeプロトコル用に設定および使用できます。

最高のパフォーマンスと最高の可用性を実現するには、お客様の特定の ONTAP システムに対応した https://hwu.netapp.com["NetApp Hardware Universe"^]に記載されている推奨ターゲットポート構成を使用してください。

各オンボードFCポートおよび拡張アダプタポートは、サポートされている速度に応じて個別に設定できます。対応速度は、ONTAPシステムおよびHBAによって異なります。特定のホストが使用するすべてのターゲットポートは、同じ速度に設定する必要があります。

ベストプラクティスとして、イニシエータ、スイッチ、およびターゲットポートのすべてに共通の速度を設定することをお勧めします。ポートとイニシエータの速度が異なり、共通の速度をネゴシエートできない場合、セッションを確立できません。ポート速度の設定に自動ネゴシエーションを使用することは推奨されません。自動ネゴシエーションは、セッションの確立や中断後の再接続を遅らせる可能性があります。

サポートされている速度は、各 ONTAP システムの NetApp Hardware Universe の「サポートされているアダプターカード」に記載されています。

.手順
. link:https://hwu.netapp.com["NetApp Hardware Universe"^]に移動します。
. *製品*を選択します。
. *プラットフォーム*で、お使いのシステムの種類を選択してください。
. 特定のシステムを選択し、次に ONTAP バージョンを選択します。
. 「結果を表示」を選択し、次に「サポートされているアダプターカード」を選択します。
+
FC アダプタカードは *Category* の項目で「Block Access (Target)」としてリストされており、サポートされている速度は *Supported Protocol(s)* の項目に記載されています。
