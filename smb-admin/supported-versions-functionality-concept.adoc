= サポートされているONTAP SMBのバージョンと機能
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
サーバーメッセージブロック（SMB）は、Microsoft Windowsクライアントおよびサーバーで使用されるリモートファイル共有プロトコルです。ONTAPはすべてのSMBバージョンをサポートしています。ONTAP SMBサーバーが、お客様の環境で必要とされるクライアントと機能をサポートしていることを確認する必要があります。

ONTAPがサポートする SMB クライアントおよびドメインコントローラに関する最新情報は、_Interoperability Matrix Tool_ で入手できます。

SMB 2.0以降のバージョンは、ONTAP SMBサーバーでデフォルトで有効になっており、必要に応じて有効または無効にすることができます。同様に、SMB 1.0も必要に応じて有効または無効にすることができます。

ONTAP 9.20.1以降、ONTAPは開いているファイルとディレクトリに対するSMB正規化名前クエリをサポートします。Windowsクライアントは、単一のリクエストで正規のファイル名とディレクトリ名を取得できます。

[NOTE]
====
ドメインコントローラへの SMB 1.0 および 2.0 接続のデフォルト設定は、ONTAP のバージョンによっても異なります。 `vserver cifs security modify` コマンドの詳細については、link:https://docs.netapp.com/us-en/ontap-cli/vserver-cifs-security-modify.html["ONTAPコマンド リファレンス"^] を参照してください。SMB 1.0 を実行している既存の CIFS サーバを使用している環境では、セキュリティとコンプライアンスの強化に備えるため、できるだけ早く新しいバージョンの SMB に移行することを NetApp では推奨しています。詳細については、NetApp の担当者にお問い合わせください。

====
