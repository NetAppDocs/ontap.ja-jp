= ONTAP System Managerのダッシュボードからクラスタ情報を表示する
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
System Managerのダッシュボードでは、ONTAPクラスタを1箇所ですばやく包括的に確認できます。

System Managerのダッシュボードからは、クラスタの状態、容量、ネットワーク、パフォーマンスに関する情報を表示できます。これには、重要なアラート、ストレージ階層とボリュームの効率と容量、クラスタノードの状態と可用性、最もアクティブなアプリケーションとオブジェクト、パフォーマンスメトリックなどが含まれます。

ONTAP 9.19.1以降、SVM管理者はONTAP System Managerの専用SVM管理者ダッシュボードを使用して、自身のSVMを監視および管理できます。詳細については、link:task-svm-admin-dashboard-sm.html["System Managerを使用してSVMを管理および監視する"]を参照してください。

ダッシュボードは次の4つのパネルで構成されています。



[[view-the-cluster-health]]
== クラスタの状態を表示する

ONTAP System Managerダッシュボードの*Health*セクションでは、名前、ONTAPバージョン、作成日など、クラスタに関する一般的な情報を表示できます。また、クラスタノード全体の健全性、クラスタレベルのエラー、警告、アラート、およびクラスタのパフォーマンスを向上させるための推奨変更点を確認することもできます。

ONTAP 9.20.1以降では、クラスターまたはストレージ仮想マシン（SVM）の証明書の有効期限が切れる30日前に、ヘルスアラートが表示されます。アラートは毎日更新され、有効期限までの残り日数が表示されます。デフォルトの30日間のアラートしきい値を0日から90日までの任意の日数に変更したり、アラートが表示されないように無効にしたり、有効期限が切れた証明書のアラートを抑制しつつ、有効期限が近づいている証明書のアラートは引き続き受信するように設定できます。

* クラスタの健全性情報を表示するには、ダッシュボードの*健全性*の横にあるimage:icon_arrow.gif["矢印アイコン"]を選択します。
* 証明書の有効期限設定を変更するには、アラートを選択し、次に*証明書の設定*を選択します。




[[view-the-cluster-capacity]]
== クラスター容量を表示する

ONTAP System Managerダッシュボードの*Capacity*セクションでは、クラスターのストレージ容量を確認できます。使用されている論理領域の合計、使用されている物理領域の合計、および利用可能なディスク容量を確認できます。

ActiveIQに登録して、クラスタの履歴データを確認することもできます。

ダッシュボードの*Capacity*の横にあるimage:icon_arrow.gif["矢印アイコン"]を選択すると、合計スペース、使用済みスペース、空きスペースなど、クラスタに関連付けられている階層の概要を含むクラスタ容量情報が表示されます。スループット、IOPS、レイテンシの詳細も表示されます。link:./concepts/capacity-measurements.html["ONTAPが使用済みストレージをレポートする方法について"]。

容量ビューを使用して、ローカル層またはクラウド層を追加することを選択できます。詳細については、link:task_admin_monitor_capacity_in_sm.html["クラスタの容量の表示"]を参照してください。



[[view-the-cluster-network]]
== クラスタネットワークを表示する

ONTAP System Managerダッシュボードの*ネットワーク*セクションでは、ネットワークの一部である物理ポート、ネットワークインターフェイス、およびストレージVMを表示できます。

ネットワークビューには、ネットワークに接続されているクライアントのタイプが表示されます。ネットワークに接続されている各クライアントは番号で表されます（例：「NVMe/FC 16」）。番号を選択すると、各ネットワーク要素の詳細が表示されます。

ダッシュボードの *ネットワーク* の横にある image:icon_arrow.gif["矢印アイコン"] を選択すると、ネットワーク上のポート、ネットワークインターフェース、ストレージVM、ホストなどを含む、ネットワークの全体像をフルページで表示できます。



[[view-the-cluster-performance]]
== クラスターのパフォーマンスを表示する

ONTAP System Managerダッシュボードの*パフォーマンス*セクションでは、パフォーマンス統計を表示して、ONTAPクラスタの健全性と効率を監視できます。統計情報には、レイテンシ、スループット、IOPSなどの主要なクラスタ性能指標が含まれており、グラフで表されています。

[Performance]ビューには、パフォーマンス統計が日、時間、週、または年という異なる時間間隔で表示されます。各種グラフを使用してクラスタのパフォーマンスをすばやく分析し、最適化が必要な可能性がある特性を特定できます。この迅速な分析は、ワークロードをどのように追加または移動するかを決定するのに役立ちます。使用量がピークになる時期を確認して変化に備えることもできます。

[Performance]ビューには、レイテンシ、スループット、IOPSに関連する全体的なパフォーマンス指標が表示されます。

9.15.1以降では、[Performance]ビューが強化され、レイテンシ、スループット、IOPSに関連する読み取り、書き込み、その他、および全体的なパフォーマンス指標のグラフが表示されるようになっています。その他の指標には、読み取りと書き込み以外の処理が含まれます。

パフォーマンス値は3秒ごと、パフォーマンス グラフは15秒ごとに更新されます。クラスタのパフォーマンスに関する情報がない場合、グラフは表示されません。

ダッシュボードの *パフォーマンス* の横にある image:icon-expansion-arrows.png["拡張アイコン"] を選択すると、時間、日、週、月、年ごとのパフォーマンス指標をフルページ表示で確認できます。ローカルシステムにパフォーマンス指標のレポートをダウンロードすることもできます。
