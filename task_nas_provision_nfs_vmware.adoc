= ONTAP System Managerを使用してVMware データストア用のNFSストレージをプロビジョニングする
:hardbreaks:
:toclevels: 1
:allow-uri-read: 
:toclevels: 1
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
ESXiホスト向けのONTAPベースのストレージシステムにNFSボリュームをプロビジョニングするためにONTAP tools for VMware vSphereを使用する前に、ONTAP 9.7以降のSystem ManagerでNFSを有効にしてください。

System Manager で link:task_nas_enable_linux_nfs.html["NFS対応ストレージVM"] を作成したら、ONTAP tools for VMware vSphere を使用して NFS ボリュームをプロビジョニングし、データストアを管理します。

現在の ONTAP と ONTAP tools for VMware vSphere リリース間の互換性を確認するには、必ず https://imt.netapp.com/matrix/["NetApp Interoperability Matrix"^]をご確認ください。

System Manager Classic（ONTAP 9.7以前のリリース）を使用してESXiホストからデータストアへのNFSアクセスを設定するには、 https://docs.netapp.com/us-en/ontap-system-manager-classic/nfs-config-esxi/index.html["ESXi の NFS 構成の概要"^]を参照してください。

詳細については、 https://docs.netapp.com/us-en/netapp-solutions/virtualization/vsphere_ontap_ontap_for_vsphere.html["TR-4597：VMware vSphere for ONTAP"^]および https://docs.netapp.com/us-en/ontap-tools-vmware-vsphere-10/["ONTAP tools for VMware vSphereのドキュメント"^]を参照してください。
