= ONTAPアップグレード期間に関するガイドライン
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAPアップグレードの準備手順に少なくとも30分、各HAペアのアップグレードに60分、アップグレード後の手順に少なくとも30分を計画してください。


NOTE: 外部キー管理サーバおよびKey Management Interoperability Protocol（KMIP）でNetApp Encryptionを使用している場合、各HAペアのアップグレードには1時間以上かかると想定する必要があります。この追加時間は、クラスタが外部KMIPキーマネージャを使用し、MetroCluster構成ではなく、HAパートナーがキーを提供できる場合、ONTAP 9.20.1から開始される自動無停止アップグレードには適用されません。ONTAP 9.20.1以降、これらのクラスタはHAパートナーからキーをリストアします。xref:../encryption-at-rest/configure-external-key-management-overview-concept.html#intracluster-key-sharing[クラスター内鍵共有]を参照してください。ONTAP 9.20.1へのアップグレードでは引き続きキーサーバからキーがリストアされるため、そのアップグレードにはHAペアあたり1時間以上かかることを想定して計画してください。

これらのアップグレード期間のガイドラインは、代表的な構成とワークロードに基づいたものです。これらのガイドラインを使用して、無停止アップグレードの実行に必要な時間を見積もることができます。実際のアップグレード プロセスに要する時間は、環境とノードの数に応じて異なります。
