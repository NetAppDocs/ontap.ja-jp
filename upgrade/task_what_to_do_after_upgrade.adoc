= ONTAPアップグレード後の検証ワークフロー
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
ONTAPのアップグレード後には、クラスタの準備状況を確認するために実行するべきタスクがいくつかあります。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["1"]クラスターを確認してください。
[role="quick-margin-para"]
ONTAP をアップグレードした後、link:task_verify_cluster_after_upgrade.html["クラスターのバージョン、クラスターの状態、およびストレージの状態を確認します。"]必要があります。MetroCluster FC構成を使用している場合は、クラスタが自動計画外スイッチオーバーに対応していることも確認する必要があります。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["2"]すべての LIF がホームポートにあることを確認します。
[role="quick-margin-para"]
再起動中に、一部のLIFが割り当てられたフェイルオーバーポートに移行された可能性があります。クラスターをアップグレードした後は、link:task_enabling_and_reverting_lifs_to_home_ports_post_upgrade.html["ホームポートに接続されていないLIFを有効にして元に戻す"]。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["3つ"]ご使用のクラスターに特有の特別な考慮事項を確認してください。
[role="quick-margin-para"]
クラスターに特定の構成が存在する場合は、link:concept_special_configurations_post_checks.html["アップグレード後に追加の手順を実行する"]。

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["4"]ディスク認定パッケージ（DQP）を更新します。
[role="quick-margin-para"]
DQPは、ONTAPのアップグレードの一部として更新されません。アップグレード後にlink:concept_when_you_need_to_update_the_disk_qualification_package.html["DQPを更新"]必要があります。
