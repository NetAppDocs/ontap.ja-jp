= FlexCloneファイルおよびFlexClone LUNを使用したONTAPのスペース削減効果の表示
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
FlexCloneファイルおよびFlexClone LUNを含むボリューム上でブロック共有によって削減されたディスク スペースの割合を表示できます。これは、キャパシティ プランニングの一環として行うこともできます。

.手順
. FlexCloneファイルとFlexClone LUNによるスペース削減量を確認します：
+
[source, cli]
----
volume show -volume <vol_name> -vserver <SVM> -fields used, sis-space-saved, dedupe-space-saved, compression-space-saved
----
+
[NOTE]
====
重複排除が有効なFlexVolボリュームでこのコマンドを実行すると、重複排除とFlexCloneファイルおよびLUNの両方によって削減されたスペースを確認できます。
